# エトキっち ゲームデザイン

## 概要

エトキチの自律した日常をスマートフォンの縦画面で眺め、同居人として時々関わるWebゲーム。

育成ゲームの数値最適化ではなく、「スマホを開くと、その時刻を生きているエトキチに会える」体験を核とする。

## 体験の原則

- エトキチはプレイヤーが見ていない間も暮らしている
- プレイヤーは画面に姿を出さない同居人
- 見逃しや放置にペナルティを付けない
- 空腹や幸福度などの最適化対象となるゲージを表示しない
- 関わりの結果は表情、後の生活、翌日の反応で示す
- 普段はかわいい暮らしを主役とし、友達の訪問や季節行事を生活の延長として加える

## エトキチ

- 「エトキチの大冒険」の性格と口調を引き継ぐ
- 一人称は「ぼく」
- 好奇心が強く、考えるより先に動く
- 人や物事の良いところを素直に見つける
- 世話焼きだが、勢い余って空回りすることがある
- 失敗しても次の方法をすぐ試す
- 語尾の「キチ！」はテンションが上がったときだけ使う

## 時間と生活

- 端末の現在時刻を早朝・朝・昼・夕方・夜・深夜の6つの生活時間帯へ分ける
- 日付と時間帯から、その時間の生活をランダムに決める
- 同じ時間帯では再読み込みしても結果を変えない
- 直近の生活と同じものは出にくくする
- 基本行動に表情、小物、独り言、食べ物などの差分を重ねる
- 低確率の珍しい日常には、長期間出会えない状態を避ける仕組みを設ける

時間帯、収録シーン、抽選規則の詳細は[初期プロト仕様](./prototype-spec.md)に記載する。

## 触れ合い

- エトキチや家具をタップする軽い触れ合いは、状態を大きく変えない
- 意味のある生活シーンでは、状況に合う関わり方を2〜3個示す
- 選択肢に正解や失敗を設けず、後に異なる反応と思い出を生む
- 意味のある関わりはその時間帯で一度だけ反映し、繰り返しの報酬稼ぎにしない

## 舞台とアート

- 窓、ベッド、机、台所が一画面に収まる小さなワンルーム
- 背景、キャラクター、生活動作を統一したドット絵で表現する
- エトキチは太い輪郭と読み取りやすい表情で、背景より大きく見せる
- 戦闘ポーズや闘技場背景は生活画面へ流用しない
- シーン図鑑では全シーンに固有のイラストを用意する

## 技術方針

- スマートフォンの縦画面を基準にする
- サーバーのない静的SPAとして配信する
- セーブデータはIndexedDBを中心にブラウザ内へ保存する
- 閉じている間は常駐処理せず、再起動時に現在時刻と保存時刻から生活を再構成する
- プロトでは複数端末同期、自動復旧、サーバー基準時刻による時計変更対策を持たない
