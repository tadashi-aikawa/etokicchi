# 部屋レイヤーと模様替え基盤

## 目的

部屋を一枚の背景画像として扱う構造から、固定レイヤー、家具、時間表現、シーン要素を独立して配置できる構造へ移行する。

この段階では模様替え画面と配置保存は追加しない。家具定義の座標を変えるだけで描画、クリック、衝突判定が同時に追随することを基盤の完成条件とする。

## レイヤー

描画順は次のとおり。

1. 空室ベース
2. 時間帯別の窓景色
3. 家具と床上のシーン要素とキャラクターを持つ深度コンテナ
4. 背景と家具だけへ適用する時間帯の照明
5. 窓枠などの前景

家具とキャラクターは同じ深度コンテナへ置く。深度コンテナは`sortableChildren`を有効にし、足元のY座標と固定の同率順位から`zIndex`を決める。移動中のキャラクターは座標と同時に`zIndex`を更新する。

窓のみみぞうは床上の要素ではないため背景側へ置く。時間帯の照明は現行表示との互換を優先し、キャラクターと同席者には適用しない。

## 家具定義

各家具は次の値を一つの定義へ持つ。

- 安定したID
- 透過素材名
- 表示名と観察文
- 配置座標
- 表示高さ
- 描画順の基準となる足元Y座標
- 床上の占有領域
- クリック領域
- 家具に結び付く行動地点

配置座標は家具画像の下中央を原点とする。占有領域、クリック領域、行動地点はその原点からのローカル座標で定義する。家具を移動すると4種類の座標が同じ差分だけ追随する。

占有領域は画像の外接矩形ではなく、キャラクターの足元が侵入できない床面だけを表す。背の高い家具の表示領域をそのまま占有領域にすると、家具の手前にある歩行可能な床まで塞いでしまうためである。クリック領域は家具Sprite自身のローカル`hitArea`として設定し、キャラクターより前面の透明レイヤーを作らない。

## 経路と衝突

- 歩行可能範囲はキャラクターの足元半径だけ内側へ縮めた部屋内の矩形で定義する
- 家具の占有領域は、足元半径とのMinkowski和により膨張させる
- 境界への接触も衝突として扱う
- 各移動区間は線分と軸平行矩形の連続判定を使う
- シーン経路は起動前に全区間を検証する
- 実行時の移動も同じ判定を通す
- 経路が成立しない家具配置は採用せず、直前の有効配置へ戻す
- 家具を目的地にする行動は家具IDと行動地点IDで解決し、家具移動後も停止位置を追随させる
- 歩行しない配置は`nonWalking`として明示し、睡眠シーン名による例外判定を作らない

## 時間帯

空室ベースと家具素材は時間帯で共用する。空室ベースから昼の日差しと窓景色を除き、時間中立の素材にする。窓部分は既存の6背景から切り出して時間帯ごとに差し替え、背景と家具は時間帯別の照明オーバーレイで変化させる。窓素材は論理座標`195×347`へ正規化して扱う。

描画指定は`layered`と`legacy`の判別可能なUnionにする。`布団を蹴飛ばしている`は、床の布団と関わり後の掛け布団が旧背景へ焼き込まれている。見た目と保存済みの関わり結果を維持するため、このシーンだけは旧背景、旧照明位置、旧キャラクター順を一まとまりにした互換描画として残す。

## 検証

- 家具ID、描画順、占有領域、クリック領域の妥当性をユニットテストする
- 全活動シーンの経路が家具の占有領域を横切らないことをテストする
- 家具座標を変えても、占有領域とクリック領域が同じ差分だけ移動することをテストする
- 食卓、水やり対象、ベッドの行動地点が家具移動後も追随することをテストする
- 6時間帯で異なる窓素材と照明が選ばれることをテストする
- 全22シーンを同じ条件で表示する画像回帰の確認表を用意する
    - `布団を蹴飛ばしている`の未選択、布団を掛けた後、その他の選択
    - 星見のみみぞう有無
    - みみぞう訪問の出現、振り向き、退場
- 全表示を通過するまで新レイヤー描画を既定にしない
