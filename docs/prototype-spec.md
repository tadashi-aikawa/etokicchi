# エトキっち 初期プロト仕様

## 体験の核

スマートフォンを開くと、その時刻を生きているエトキチに会える。

- プレイヤーは画面に姿を出さない同居人
- エトキチは見ていない間も自律して暮らす
- 見逃しや放置にペナルティを設けない
- 空腹や幸福度などの最適化対象となるゲージを表示しない
- 関わりの結果は表情、後の生活、翌日の反応で示す

## 時間帯

| ID | 時刻 | 生活シーン |
|---|---|---|
| `earlyMorning` | 5:30以上7:30未満 | もうすぐ目が覚めそう<br>朝のストレッチ<br>今日の予定を考える<br>タツヲが起こしに来た<br>みみぞうを見送る |
| `morning` | 7:30以上11:00未満 | 朝食を作りすぎる<br>寝坊して支度する<br>朝いちばんのお茶を飲む<br>クーンちゃんを朝ブラシする |
| `daytime` | 11:00以上15:30未満 | 掃除中におもちゃを見つける<br>窓辺で昼寝する<br>クーンちゃんを枕に昼寝する<br>植物へ水やりする |
| `evening` | 15:30以上19:00未満 | 泥だらけで帰宅する<br>夕食を煮込む<br>洗濯物をたたむ<br>タツヲがソファーでくつろぎすぎる<br>クーンちゃんを抱きしめる |
| `night` | 19:00以上23:00未満 | 明日の持ち物を準備する<br>小さな夜食を楽しむ<br>漫画の続きを読む<br>みみぞうが窓からのぞいている |
| `deepNight` | 23:00以上翌5:30未満 | 布団で眠る<br>タツヲと寄り添って眠る<br>布団を蹴飛ばして眠る<br>窓辺で星を数える |

- 早朝は眠りから目覚めへ移る時間、朝は起きた後の生活を始める時間とする
- 次のシーンは前提シーンを発見した後だけ抽選対象にする
    - `朝のストレッチ`は`もうすぐ目が覚めそう`の発見後に解放する
    - `クーンちゃん枕でお昼寝`は`クーンちゃんの朝ブラシ`の発見後に解放する
    - `タツヲと眠る夜`と`タツヲ、くつろぎすぎ`は`タツヲが起こしに来た`の発見後に解放する
    - `みみぞうが窓からのぞいている`は`窓辺で星を数えている`の発見後に解放する
    - `みみぞうを見送る`は`みみぞうが窓からのぞいている`の発見後に解放する
- 条件の追加前に対象シーンを発見済みなら、前提シーンが未発見でも解放済みとして扱う
- 深夜のslotは23:00側のローカル日付へ帰属させ、0:00以上5:30未満に日付を跨いでも同じslotを維持する。5:30ちょうどは早朝に帰属する
- 表示中は分の境界ごとに右上の時計と壁時計を現在時刻へ更新する
- 時間帯の境界を越えたら、新しいslotのシーンへ再読み込みなしで切り替える
- 非表示タブから戻ったときは、バックグラウンド中のタイマー遅延に依存せず現在時刻へ同期する
- 開発用の`time`クエリを指定した画面は、指定日時のまま固定する

## シーン決定

- `ローカル日付 + 時間帯`を一つのslotとする
- 同じslotでは、再読み込みしてもシーンとランダム差分を変えない
- 時間帯ごとに同じシーンが3回連続しない
- 表情、小物、独り言はシーン決定と別のseedで選ぶ
- 初めて作ったslotだけ、発見回数を1増やす

開発時は `debug=random` クエリを付けると、指定した時間帯を維持したまま、シーンとランダム差分を再読み込みごとに一時抽選する。デバッグ中の状態は通常の保存領域へ書き込まない。

`debug=random`と`scene`クエリを併用すると、Lock状態に関係なく指定シーンを一時表示する。`time`は指定シーンの時間帯に合わせる。

## 画面と生活ルーチン

- 低解像度のドット絵ワンルームをスマートフォン画面へ拡大表示する
- 部屋背景は6時間帯ごとに用意し、窓外の空・街明かり・室内へ差し込む光を現在時刻に合わせる
- 活動中のエトキチは、シーンごとに決めた家具間の経路を歩行し、立ち止まると生活内容に合う動作を繰り返す
- 活動中の全シーンに、その暮らしの内容が読み取れる3コマの専用アニメーションを表示する
- 暮らしの跡が残るシーンには、家具や床へ重ねるシーン小物を配置する
    - `作りすぎた朝食`は食卓の天板へ朝食の皿を置き、エトキチが食卓の椅子へ着いた時点で現れる
    - `泥だらけで帰ってきた`は玄関から室内へ続く泥の足跡を、床装飾の直上・家具より奥へ敷く
    - `洗濯物をたたんでいる`は、たたむ場所の右脇へ洗濯かごを置く
    - `懐かしいおもちゃ発見`は、探している場所の左脇へおもちゃ箱を置く
- `窓辺で星を数えている`のエトキチは、ベッドの上ではなく窓の下・ベッドと本棚のあいだの床に立ち、窓へ向いた後ろ姿を表示する
    - 望遠鏡と重なるベッド脇の照明台は、このシーンのあいだだけベッドの足元へどける
- `みみぞうが窓からのぞいている`では、お茶を飲むエトキチ、窓越しに現れるみみぞう、窓へ振り向くエトキチ、ゆっくり去るみみぞうの流れを繰り返す
    - エトキチは家具の無い床ではなく、`朝いちばんのお茶`と同じ食卓の椅子へ座らせる
- みみぞうとの初回遭遇後は、深夜の`窓辺で星を数えている`へ同席差分を決定的な低確率で表示する
- キャラクターは背景と同じドット単位で描き、太い輪郭とはっきりした目・口・頬でスマートフォン上でも読める大きさにする
- 睡眠中は歩き回らず、ベッド上で呼吸と小さな寝返りを繰り返す
- `すやすや眠っている`は既存ベッドの掛け布団から顔と手だけを出した寝姿、`布団を蹴飛ばしている`は掛け物なしの寝姿と床へ落ちた布団を通常画面に表示する
- `タツヲと眠る夜`は、布団から顔を出したエトキチと、ベッド脇で頭と長い腕を寄せて眠るタツヲを別々の透過スプライトで表示する
    - 呼吸の伸縮はエトキチだけに適用し、タツヲの輪郭は変形させない
- `タツヲが起こしに来た`は、エトキチの顔を隠さないようタツヲをベッド右側へ寄せて表示する
- `タツヲ、くつろぎすぎ`は、片手で頭を支えて眠るタツヲを二人掛けソファーの前後2つの着席地点へ追随させ、困り顔のエトキチをソファー脇へ表示する
    - タツヲの配置と描画深度は別々の着席地点から解決し、家具を移動しても寝姿が追随する
    - クーンちゃんは手前の絨毯から二人を見守る
- `大丈夫だよー`は、雷を怖がるクーンちゃんをエトキチが手前の絨毯で抱きしめる
    - 窓のガラス面にだけ斜めの雨を流し、カーテンより奥に見える重なり順を保つ
    - 黄色い雷光、震え、抱きしめ直し、「大丈夫だよー」のフキダシ、落ち着く様子を周期的に繰り返す
    - フキダシのしっぽは、台詞を話すエトキチ側へ向ける
    - エトキチは小さな丸い胴を残し、脚だけを短くした体型にする
    - 二人を一体の透過スプライトとして表示し、震えと抱きしめ直しは位置と拡縮で表現する
- `窓辺でお昼寝`は、日の当たる窓辺へ置いた座布団の上で、読みかけの本を胸に大の字で眠る専用スプライトを表示する
    - 座布団を静止レイヤー、エトキチと本を呼吸レイヤーに分け、座布団は伸縮させない
- `植物へ水やり`の行動アニメーションには植物を含めず、部屋にある鉢の隣へ移動してじょうろを向ける
    - テーブル上の鉢には下向き、右下の床置き鉢には横向きの水やりアニメーションを表示する
- `布団を蹴飛ばしている`で`そっと布団を掛ける`を選ぶと、床の布団を大の字のエトキチへ掛けた通常画面へ即時に切り替え、再読み込み後も維持する
- 家具・設備・窓をタップしたときの観察文はシーンごとに上書きし、そのシーンで起きている出来事が読み取れる文にする
    - 窓の観察文はシーン上書きが無ければ6時間帯ごとの既定文を使い、`布団を蹴飛ばしている`のベッドは布団を掛けたあとの文へ切り替わる
- 容量の大きい部屋背景とアニメーション素材はWebP、小さな透過スプライトはPNGを使用する
- Canvasの描画解像度は2とし、素材は「表示する論理寸法のちょうど2倍」のピクセル寸法で持つ
    - 描画時のSpriteの拡大率は既定の用途で正確に0.5になり、素材のドットが画面へ1対1で乗る
    - 例外は、同じ素材を場面ごとに違う大きさで使う4点と、水やりで食卓の鉢へ向く姿の拡大とする
        - どちらもテストへ正とする用途を明記し、未申告の食い違いが増えたら落ちるようにする
    - 背景と窓は390×694px、家具・設備・装飾は定義の表示寸法の2倍とする
    - 時間帯の照明フィルターも解像度2で描き、中間テクスチャで2倍化が打ち消されないようにする
    - 原素材は`assets-src/`に置き、`pnpm assets:normalize`で`public/assets/`へ機械変換する
    - 縮小はLanczos、等倍のドット絵の拡大は最近傍の整数倍にする
- Canvasの390×844pxが端末ピクセルの整数倍へ乗る大きさでCSS拡大する
    - 整数倍にすると当てはめ幅の75%を下回る画面では、整数倍を諦めて画面へ当てはめる
    - ドットの太さが揃わないことより、部屋が極端に小さくなることを避ける
- 歩行アニメーションは3列×4行(下・左・右・上)の透過WebPとし、1コマ96×104pxで足元をコマ下端の2px上へ揃える
- 行動アニメーションは1方向につき360×120pxの透過WebPとし、120×120pxの3コマを横一列に配置する
    - 複数方向を持つ場合は方向ごとに行を増やし、水やりは横向きと下向きの2行を持つ360×240pxとする
    - `大丈夫だよー`は、抱擁姿勢を保ったままプログラムで震えと拡縮を付けるため例外とする
- 図鑑と実績解除のイラストは512×512pxのWebPとし、全シーンで異なる構図を使用する
- 通常時は部屋とエトキチを主役にし、現在の暮らしと短い独り言だけを下端へ表示する
- 詳細説明、選択肢、後続反応はタップ時だけ下部シートへ表示する
- 下部シートは下端の「見る/関わる」ボタンからだけ開く
- 下部シートの開閉時は、背後の部屋とHUDの画面位置を変えない
- エトキチのセリフは、部屋の中でエトキチ本体の頭上へ浮かぶ白いフキダシへ表示する
    - 初期状態は非表示とし、エトキチ本体のタップで6秒間だけ表示する。再タップで表示時間を延長する
    - フキダシはエトキチへ追随し、歩行中や寝ている姿でも頭上に付いて動く
    - 左右が部屋からはみ出す場合は内側へ寄せ、しっぽだけをエトキチの頭上に残す
    - 上端がトップバーへ食い込む場合は、エトキチの左右で空いている側へフキダシを出す
    - 思考フキダシと同時に出るシーンでは、思考フキダシを隠してセリフを優先する
- 家具・設備・窓・クーンをタップした観察文はHUD内の観察行へ🔍付きの対象名チップと並べて表示し、次のタップまで残す
- 下部シートは「いまのようす」「よく見ると」「エトキチ」「つづき」「どうする？」「エトキチの返事」の見出しで段落を区切り、セリフには顔アイコン、選択肢には絵文字アイコンを添える
- 図鑑の未発見カードはシーン固有色を使わず、未遭遇は共通の固定色、ロック中は解放段階を表す金属色で表示する

### 部屋のレイヤーと模様替え基盤

通常の部屋は、次の順に分離して描画する。

1. 時間中立の空室ベース
2. 既存の6時間帯背景から窓部分だけを表示する窓レイヤー
3. 玄関とカーペットを置く床装飾レイヤー
4. 壁際の固定設備レイヤー
5. 時計を置く壁装飾レイヤー
6. 窓の来客と窓枠の前景
7. 家具、床上のシーン要素、キャラクターをまとめた深度コンテナ
8. 背景、窓、装飾、家具だけへ適用する時間帯Tint

深度コンテナは足元Y座標で並べ替える。同じY座標では、家具定義とキャラクター種別ごとの固定順位を使う。歩行中のキャラクターは座標と同時に描画順を更新する。窓からのぞくみみぞうは床上にいないため、深度コンテナではなく窓側へ置く。

家具は、安定ID、透過素材、下中央アンカー、表示高さ、足元Y座標、床面の占有領域、クリック領域、行動地点を一つの定義に持つ。占有領域、クリック領域、行動地点はアンカーからのローカル座標とし、家具移動時に同じ差分で移動する。クリック判定とイベントは家具Sprite自身へ設定する。

キャラクターの歩行判定では、足元半径だけ部屋の歩行可能範囲を内側へ縮め、家具の占有AABBをMinkowski和で膨張させる。線分と膨張AABBの連続判定では境界接触も衝突とする。配置候補は全活動シーンの循環経路を含めて検証し、無効な場合は採用せず直前の有効配置を維持する。実行時の各移動も同じ判定を通す。

食卓、ベッド、水やり対象を目的地にする行動は、家具IDと行動地点IDで解決する。冷蔵庫、流し台、コンロを目的地にする行動は固定設備IDと物理行動地点IDで解決する。歩行しないシーンは`nonWalking`として明示する。全シーンで`layered`描画を使う。`布団を蹴飛ばしている`では布団のないベッド、寝姿、床の布団を分離し、床の布団をベッドへ追随させる。`cover`選択後は床の布団を消し、掛け布団を含む寝姿へ切り替える。`夕食をことこと煮込む`では固定キッチンへ鍋と、食卓右から移動した丸椅子を追随させる。エトキチは丸椅子の上から手ぶらで鍋を見つめ、期待感はキャラクターへ追随する汎用思考フキダシで表現する。`洗濯物をたたんでいる`は奥側のカーペット、`タツヲ、くつろぎすぎ`は二人掛けソファー、`明日の持ち物を準備`は玄関横の棚を基準に配置する。

壁時計はHUDと同じ日時から時針と分針を算出する。カーペットと玄関は歩行可能な床装飾として家具とキャラクターの背面へ描画する。

右壁の冷蔵庫、流し台、コンロは一体の固定設備として扱い、模様替え対象から外す。設備本体を右壁へ密着させ、部屋の構図と同じ浅い奥行き角度にする。ベッド脇にはホテルの照明台を置く。左壁には右向きの二人掛けソファーを置き、前後2か所の着席地点を持たせる。ソファー前の絨毯には大型猫のクーンを独立オブジェクトとして配置し、エトキチは「クーンちゃん」と呼ぶ。`漫画の続きに夢中`では右向きの座り読み素材をソファーへ重ね、クーンはベッドへ移す。`洗濯物をたたんでいる`では横向きのクーンをソファーへ移し、`窓辺でお昼寝`では日なたへ移す。`小さな夜食を楽しむ`では食卓の足元からエトキチを見つめ、まばたきする。食卓、ソファー、床の鉢植えは室内構図に合わせた表示寸法を家具定義へ持たせる。

## 意味のある関わり

各時間帯の代表1シーンだけに2〜3個の選択肢を設ける。選択はslotごとに一度だけ保存する。

- 選択直後にエトキチの反応を返す
- 次の時間帯に、台詞か室内の小さな変化を返す
- 翌日の同じ時間帯に、覚えていることを示す反応を返す
- 正解、失敗、数値報酬は設けない

## シーン図鑑と達成度

- シーンを初めて見たときに実績解除を表示し、図鑑の発見数を更新する
- 実績解除には、そのシーン固有の図鑑イラストを添える
- 発見済みシーンは、タイトル、時間帯、初回日時、遭遇回数をカードで表示する
- 未発見シーンは、時間帯だけを残してタイトルを `？？？` と表示する
- 未発見シーンの状態を次の2種類に分ける
    - 現在も抽選対象のシーンは「未遭遇」とし、この時間帯で出会えることを示す
    - 前提条件を満たすまで抽選対象にならないシーンは「ロック中」とし、解放条件を示す
- 図鑑はスマートフォン縦画面で2列表示し、時間帯ごとのグループと絞り込みで全26シーンを閲覧する
- 各カードへシーン固有のドット絵イラストを使用し、未発見カードでは内容を判別できないよう暗くぼかす
- 発見済みカードを選ぶと、シーン名と時間帯を添えて図鑑イラスト全体を拡大表示する。未発見カードは開けない
- 各シーンの遭遇回数を、1回、2回、3回、5回、10回、25回、50回、100回の8段階の達成度として表示する
    - 100回を超えても実際の遭遇回数は保持し、達成度は最高段階として表示する
- `すやすや眠っている` は、エトキチの顔だけが見えるよう布団に入った寝姿で表現する
- `タツヲと眠る夜`は、布団で眠るエトキチへタツヲがベッド脇から頭と腕を寄せる構図で表現する
- `布団を蹴飛ばしている` は、エトキチが掛け物なしで寝ており、布団がベッドから床へ落ちた寝姿で表現する
- 初期プロトから保存している発見履歴をそのまま使用する

## 保存

IndexedDBの単一stateレコードへ次を保存する。

- slotごとのシーンIDとランダム差分
- 時間帯ごとの直近シーン履歴
- slotごとの関わり
- 後の時間帯と翌日に表示する反応
- シーンごとの初回閲覧日時と閲覧回数

DBのschema versionとstateのdata versionを別に持つ。DB構造の変更は`onupgradeneeded`、state形式の変更は読み込み後のmigrationで扱う。

- 5時間帯のstate version 1は6時間帯のstate version 2へ読み込み時に移行する
- 旧`earlyMorning`の割当・履歴・選択は新`morning`へ移し、新`earlyMorning`の履歴は空で始める
- 旧`deepNight`の割当・選択は、slot日付を1日前へ移して23:00側の日付基準に揃える
- 旧の後続反応は発生元の時間帯と`kind`に応じて次のように移す
    - 旧`deepNight`から次の時間帯へ送った`later`は、対象の`earlyMorning`と日付を維持する
    - 旧`night`から次の時間帯へ送った`later`は、対象の`deepNight`を1日前へ移す
    - 旧`earlyMorning`から翌日の同じ時間帯へ送った`nextDay`は、対象を新`morning`へ移す
    - 旧`deepNight`から翌日の同じ時間帯へ送った`nextDay`は、対象日付を1日前へ移す
    - 後続反応の`sourceSlotKey`と`id`内の発生元slotも、移行後の割当キーに揃える
- 発見履歴とその他の時間帯の履歴は維持する

## 初期プロトに含めないもの

- サーバーと複数端末同期
- ブラウザデータ消失時の自動復旧
- 時計変更への対策
- 恒久的な関係性ゲージ
