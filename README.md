# エトキっち

時刻に応じて変わるエトキチの暮らしを、スマートフォンからそっと覗く生活観察プロトタイプです。

## 起動

Node.js 24とpnpm 11.17を使用します。miseを使う場合は、リポジトリ直下で次を実行します。

```console
mise install
pnpm install
pnpm dev
```

ブラウザで `http://127.0.0.1:4173/etokicchi/` を開きます。

任意の日時を確認したい場合は、開発用の `time` クエリを指定できます。

```text
http://127.0.0.1:4173/etokicchi/?time=2026-08-31T06:00:00
```

同じ時間帯のシーンと差分を再読み込みごとに一時抽選したい場合は、`debug=random` を加えます。デバッグ中の選択や発見は通常のIndexedDBへ保存されません。

```text
http://127.0.0.1:4173/etokicchi/?time=2026-08-31T06:00:00&debug=random
```

初めて見た暮らしは実績として解除され、左上の「図鑑」から発見済みシーンと遭遇回数を確認できます。

## 検証

```console
pnpm check
```

型検査、Lint、フォーマット検査、単体テスト、本番ビルドをまとめて実行します。

## 仕様

収録シーン、時間帯、保存方針は [初期プロト仕様](docs/prototype-spec.md) を参照してください。
